# data/

- `raw/` — committed source data (small, classroom-sized). Do not edit.
- `processed/` — generated by `scripts/prepare.py` (or the `prepare` DVC
  stage). Regenerate, never hand-edit.
- `notebooks/` (repo root) — drop the Session 5–6 class notebooks here to read
  them side by side with `src/`: each notebook cell has a matching function.
